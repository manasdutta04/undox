# Submission pack checklist

Recording and social posting are manual — this repo ships the scripts and drafts.

## Before submit

- [ ] Record 3-minute demo following [`DEMO_SCRIPT.md`](./DEMO_SCRIPT.md) (approval + kill/restart mandatory)
- [ ] No real PII / keys / `.env` on camera
- [ ] Publish or attach [`FIELD_REPORT.md`](./FIELD_REPORT.md) for Field Report prize
- [ ] Cut 1–2 clips from [`SOCIAL_CLIPS.md`](./SOCIAL_CLIPS.md); tag WeMakeDevs / TrueFoundry / Qodo
- [ ] README stranger path verified cold (&lt;15 min)
- [ ] Qodo evidence links current (PR #3 + this deepen PR)

## Video file

Place the final MP4 outside the repo or in a private drive link — do **not** commit large binaries.
